# GasStationApp - Система управління АЗС

> Десктопний застосунок для автоматизації роботи автозаправної станції, розроблений з використанням об'єктно-орієнтованої парадигми на C# + WPF .NET
---
## Про проєкт

**GasStationApp** - це програмна система для внутрішнього використання персоналом АЗС. Система автоматизує облік палива, управління продажами, роботу з бонусними картками клієнтів та формування звітності.

Проєкт розроблено в рамках курсового проєкту з дисципліни **«Об'єктно-орієнтоване програмування»**.

## ✨ Функціональні можливості

### 👤 Адміністратор
- Управління типами палива (додавання, редагування, видалення)
- Управління резервуарами (додавання, редагування місткості, поповнення)
- Управління бонусними картками клієнтів
- Перегляд фінансового звіту та статистики операторів
- Збереження та завантаження даних у форматі JSON

### 👔 Менеджер
- Поповнення залишків палива в резервуарах
- Створення та редагування бонусних карток
- Перегляд загальної статистики продажів

### 🧑‍💼 Оператор
- Проведення продажів палива з автоматичним розрахунком суми
- Нарахування та списання бонусів за карткою клієнта
- Перегляд поточних цін та залишків палива
- Формування звіту за зміну
---
## 🔒 Система безпеки
- Авторизація з перевіркою логіну та паролю
- Автоматичне блокування акаунту після 3 невдалих спроб входу на 5 хвилин
- Фіксація часу входу та виходу для кожного оператора

## 🎯 ООП концепції в проєкті

| Концепція | Де реалізовано |
|---|---|
| Абстрактний клас | `User` - базовий клас для всіх користувачів |
| Спадкування | `Administrator`, `Manager`, `Operator` : `User` |
| Поліморфізм | `GetRole()`, `LogIn()`, `LogOut()` |
| Інкапсуляція | `BonusBalance`, `PricePerLiter`, `CurrentLevel` |
| Інтерфейси | `ISaveable`, `IReportable` |
| Делегати і події | `LowFuelEventHandler`, `LowFuelWarning` в `Tank` |
| Статичні члени | `_nextId`, `BlockDurationMinutes`, `GenerateCardNumber()` |
| Collections.Generic | `List<T>`, `Dictionary<K,V>` |
| LINQ | `Where`, `Sum`, `FirstOrDefault`, `Select`, `Any` |
| Серіалізація | `JsonSerializer` в `Administrator` |
